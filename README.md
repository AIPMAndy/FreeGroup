# FreeGroup

一个免费的社群入口页。改一个配置文件，就能给自己的一堆群做一个统一的加入页。

**在线示例：** [AIPMAndy.github.io/FreeGroup](https://aipmandy.github.io/FreeGroup/)

---

## 为什么会有这东西

把一群人聚在群里，绕不开三个物理事实：

1. **群有上限。** 微信群二维码 7 天过期，扫码入群有人数上限；飞书群最多也就几千人。人一多必然要开新群。
2. **链接会死。** 每开一个新群，就要重新发一遍码；旧的码指向一个满员群，还在继续吃流量。
3. **入口会散。** 抖音一个码、小红书一个码、公众号一个码，发出去就收不回来。

FreeGroup 只做一件事：把「加入哪个群」这个易变的东西，从页面里抽出来放进 `config.js`。门面不动，数据随时改。

## 它不是什么

- 没有后端、没有数据库、没有统计
- 不做成员管理、不审核、不发消息
- 不解决「人为什么要进群」——那是文案的事

## 30 秒用起来

1. Fork 这个仓库
2. 改 `config.js`（下面有字段说明）
3. 仓库 Settings → Pages → Source 选 `main` / `root`
4. 等一分钟，访问 `https://<你的用户名>.github.io/FreeGroup/`

不用构建、不用装依赖、不用 CI。`index.html` 是一个自包含的单文件，双击也能在本地打开。

## 配置文件

只需要动 `config.js` 一个文件。

```js
window.FREEGROUP = {
  site: {
    title:  "群的名字",
    lead:   "一句话说清这是什么",
    brand:  "左上角的标识",
    brandUrl: "点它跳到哪"
  },

  groups: [
    {
      id:       "a",           // 显示用的短编号，一个字符最好
      name:     "群的完整名字",
      members:  96,            // 当前人数
      capacity: 500,           // 人数上限
      url:      "群分享链接",   // 有效期记得设成「永久」
      qr:       "assets/qr-a.png",  // 二维码图片；没有就填 null
      status:   "open"         // open 可加入 / full 已满 / closed 暂停
    }
  ],

  offer:  [ { title: "一句话", text: "一句解释" } ],
  rules:  [ "群规一", "群规二" ],
  owner:  { name, line, note, contact },
  alt:    { enabled, divider, title, text, id, qr },   // 备用入口，见下
  footer: { project, projectUrl, projectNote }
};
```

### 备用入口：给不想装飞书的人留一条路

飞书群链接永久有效、内容能沉淀，但**进群要先下载注册**。对泛流量的免费群，这一道门槛会吃掉大部分转化。所以页面默认在飞书二维码下面留了一条微信路径：

```js
alt: {
  enabled: true,                              // false 就整块隐藏
  divider: "或者",
  title:   "不想装飞书",
  text:    "加微信，备注「学习圈」，拉你进微信群。",
  id:      "AIPMAndy",                        // 微信号，会单独高亮显示
  qr:      null                               // 有微信二维码就填 "assets/wechat.png"
}
```

这是取舍不是妥协：**飞书承接愿意为深度内容装 App 的人，微信承接只想先看看的人**。两条路并存，谁都不挡谁。

### 三个字段会自己算

`groups.length`、`members` 总和，页面顶部会自动统计，不用手写。改了群列表，数字跟着变。

### 默认推荐哪个群

页面打开时自动选中**人最少的可用群**（`status` 为 `open`、`members` 最小）。想固定顺序，把那个群的 `members` 改成最小值即可。

### 群满了怎么办

把该群的 `status` 改成 `"full"`，它会显示成满员、不可点，并自动推荐下一个。开好新群后追加一条即可，不用动别的地方。

## 二维码怎么准备

任何能生成二维码的工具都行。命令行最快的做法：

```bash
# 装了 qrencode 的话
qrencode -o assets/qr-a.png -s 10 -m 3 -l M "你的群分享链接"
```

也可以用飞书自带的群二维码：群设置 → 群二维码 → 有效期改成「永久」→ 保存图片，重命名成 `assets/qr-a.png`。

> **注意**：分享链接一定要设成「永久」或「1 年」。飞书默认给的链接是 7 天，7 天后你页面上就全是死链，而且你不会收到任何提示。

## 平台差异

| 平台 | 群链接有效期 | 单群上限 | 加入门槛 |
| --- | --- | --- | --- |
| 微信群 | 二维码 7 天 | 扫码进群 200 人 | 点一下就是群，几乎零摩擦 |
| 飞书群 | 可设永久 | 基础版认证后 500 人 | 需要下载注册，手机号（+86） |
| 企业微信客户群 | 官方活码，满员自动切 | — | 需要企业主体 |

这套页面在哪个平台都能用，但**摩擦系数不同**。飞书的好处是链接永久、内容可检索、能挂知识库；代价是要装 App。面向泛流量的免费群，先用微信群；面向愿意为深度内容装一个 App 的人，飞书更合适。

## 动手改样式

所有样式在 `index.html` 顶部的 `:root` 里：

```css
--paper:     #f7f3ea;   /* 纸 */
--ink:       #1b1611;   /* 墨 */
--gold:      #bc9b6a;   /* 金，用于强调 */
```

改这三个就能换整套气质。字体走的是系统栈（衬线用 Songti SC / Georgia，数字用等宽），不依赖任何外部字体服务，国内打开不会卡在字体加载上。

## 已验证的边界

- 手机 390px / 桌面 1200px 均无横向溢出
- 5 个群切换时按钮链接与二维码同步更新
- 全部群满员时，按钮显示禁用态，文案变成「全部满员了，等新群」
- 群标题、成员数、剩余席位由 `config.js` 算出，不手写、不会和配置打架
- 关掉 JS 时只显示一条提示，群列表不可用（正文是脚本渲染的）
- `prefers-reduced-motion` 下所有过渡关闭
